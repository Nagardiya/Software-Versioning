# Software-Versioning :>
Software versioning is a system used to identify and track different versions or releases of a software using version numbers.


### Definition

**Software versioning** is a system used to identify and track different versions or releases of a software using version numbers.

### Three Components

Software versions commonly follow:

**MAJOR.MINOR.PATCH**

#### 1. Major

Used for **breaking changes** that may require existing users or clients to modify their code.

Example: `1.2.3 → 2.0.0`

#### 2. Minor

Used when adding a **new backward-compatible feature**.

Example: `1.2.3 → 1.3.0`

#### 3. Patch

Used for **bug fixes and small corrections** without changing existing functionality.

Example: `1.2.3 → 1.2.4`

### Release

A **release** is when the completed changes are tested, checked, versioned, and officially made available to users.

**Flow:**
`Changes → Testing → Final Check → Version Update → Release`
